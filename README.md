# 母子避難ナビ（Mother Shelter Navi）
妊娠期〜産後の母子向けに「最適な避難所」をレコメンドする Python アプリケーションです。
都知事杯データハッカソン2026向けに開発しています。

------------------------------------------------------------
■ プロジェクト概要
------------------------------------------------------------
災害時、妊婦さんや乳幼児を抱える家庭は「どの避難所に行けば安全か」を判断するのが難しい。
本アプリは、避難所と医療機関のオープンデータを統合し、母子に特化した観点で避難所をスコアリングします。

ユーザーの現在地から近い避難所を抽出し、以下の観点で評価します。

【実装済】
・産科までの距離
・小児科までの距離
・救急科までの距離
・医療機関の診療科情報（産科・小児科・救急科）
・医療機関の位置情報（緯度・経度）
・避難所までの距離
・ライフステージ別スコアリング（妊娠初期・中期・後期・産後）

【今後追加予定】
・避難所の安全性（構造種別・浸水リスク）
・母子向け設備（授乳室・オムツ替えスペース）
・夜間診療の有無（診療時間帯データの活用）
・避難所の混雑度（収容人数・過去データ）
・地図 UI（folium）
・API 化（FastAPI）
・フロントエンド（React）

------------------------------------------------------------
■ スコアリングロジック（概要）
------------------------------------------------------------
避難所のスコアは以下の要素から計算されます。

・避難所までの距離  
・産科までの距離  
・小児科までの距離  
・救急科までの距離  
・ライフステージ別の重み付け  

例：  
妊娠初期では「産科の近さ」を重視し、  
産後では「小児科の近さ」を重視します。
